# CodeAlpha_Stock-Trading_Platform

### Java Internship - Task 2 - Stock Trading Platform

This is a console-based Stock Trading Simulator built using Java.

**Objective:** Simulate real stock trading with virtual money.

**Features:**
- View Market Stocks (AAPL, GOOGL, TCS, RELIANCE)
- Buy Stocks with $10000 virtual balance
- Sell Stocks
- Track Portfolio and Balance
- User-friendly Menu

**How to Run:**
1. javac StockTradingPlatform.java
2. java StockTradingPlatform

**Tech Used:** Java, OOPs, Collections (HashMap, ArrayList)
